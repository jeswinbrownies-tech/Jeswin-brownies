## How to put on GitHub (GitHub Pages)

1. Create a new repository on GitHub (example name: `jeswin-sweets`)
2. Upload the `index.html` file (or clone & push)
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main` / root
5. Save → Your website will be live at:  
   `https://your-username.github.io/jeswin-sweets/`
